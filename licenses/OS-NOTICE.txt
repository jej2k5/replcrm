ReplCRM container image: operating system and runtime notices

The ReplCRM container image (ghcr.io/jej2k5/replcrm) is built on the
official Node.js image node:22.23.5-alpine3.24, pinned by digest in the
Dockerfile. Besides ReplCRM and its npm dependencies (see
THIRD_PARTY_NOTICES.md and the other files in this directory), the image
contains the Node.js runtime and Alpine Linux 3.24 packages. They are
distributed unmodified, each under its own license. ReplCRM does not
link to the GPL-licensed programs listed below.

OS-PACKAGES.txt, next to this file, is generated from the image's own
package database at build time and lists every installed Alpine package
with its exact version, license and source package ("origin").

License texts in this directory

  NODEJS-22.23.5-LICENSE.txt   Node.js and the components it bundles
  OS-GPL-2.0-only.txt          GPL-2.0-only and GPL-2.0-or-later packages
                               (alpine-baselayout, apk-tools, busybox,
                               scanelf, parts of musl-utils, gcc runtime)
  OS-LGPL-2.1-or-later.txt     gcc runtime libraries (libgcc, libstdc++,
                               libatomic)
  OS-GCC-exception-3.1.txt     GCC Runtime Library Exception for those
                               libraries
  OS-MPL-2.0.txt               ca-certificates-bundle (certificate data)
  OS-Apache-2.0.txt            OpenSSL (openssl, libcrypto3, libssl3)
  OS-musl-1.2.6-COPYRIGHT.txt  musl and musl-utils (MIT, with BSD parts)
  OS-tini-0.19.0-LICENSE.txt   tini (MIT)
  OS-zlib-1.3.2-LICENSE.txt    zlib (Zlib)
  OS-MIT.txt                   MIT terms for alpine-keys, alpine-release
                               and the MIT part of ca-certificates-bundle
  OS-BSD-2-Clause.txt          BSD-2-Clause terms referenced by musl-utils

The standard texts (OS-<SPDX identifier>.txt) are from the SPDX License
List v3.29.0; the project-specific files are from each project at the
version in the image. Alpine packages do not install license files, so
these are supplied here.

Source code

Corresponding source for every Alpine package in OS-PACKAGES.txt, at the
listed version, is published by the Alpine Linux project:

  Package build recipes (APKBUILD) and patches, branch 3.24-stable:
    https://gitlab.alpinelinux.org/alpine/aports/-/tree/3.24-stable
  Upstream source archives used by those recipes:
    https://distfiles.alpinelinux.org/distfiles/v3.24/
  apk-tools, an Alpine project:
    https://gitlab.alpinelinux.org/alpine/apk-tools (tag v3.0.9)

Node.js source for this version is at
https://github.com/nodejs/node/tree/v22.23.5.
